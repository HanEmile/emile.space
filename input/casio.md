# casio

(toc)

Merging classic casio watches should be possible right? The point of this page is to have the notes I'm writing while searching for *my* perfect casio always accessible, thus the content on this page might be not complete and subjective to my bias in taste.

Casio watches have a name and some properties. One of those properties is the "Module", that is the component within the case displaying the time. The goal here would be to find out, that cases can fit what modules. There isn't much — or any — documentation about this around, a lot of the information that can be found in the table below is from scans of casio catalogues from the 80's

I'm looking for a stainless steel [A1000](#a1000), waterproof [W86](#w86), EL [A168](#a168) casio.
