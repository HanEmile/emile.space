# uxn

These are some notes I'm taking while diving into uxn once again (had a dive into it during the [lanzarote-fuerteventura](/lanzarote-fuerteventura) trip 2022).

First of all: what version? There used to be uxn, but in the meantime, the naming has changed to `uxn<n>` with `<n>` being the id:

* uxn2: C99(SDL2)
* uxn5: javascript
* uxn11: ansi C
